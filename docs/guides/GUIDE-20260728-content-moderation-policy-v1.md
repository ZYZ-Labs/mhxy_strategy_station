# GUIDE-20260728 内容审核政策草案 v1

> 状态：已于 2026-07-29 经用户确认。第一期只处理标题、正文及用户输入的纯文本元数据。

## 1. 发布原则

- 所有用户内容先审后发。
- 任何未完成审核的内容不得出现在公共页面、公共 API、站内搜索或 MCP 中。
- 审核失败时保持待审，不允许 fail-open。
- 规则只提供风险标记和证据，每篇投稿均由管理员人工终审。
- 内容每次编辑均创建新修订并重新审核。
- 管理员通过或驳回时必须填写或选择可审计的理由。

## 2. 禁止内容

第一期禁止发布：

1. 色情、淫秽内容和招嫖。
2. 赌博、博彩、代充、资金盘及相关引流。
3. 毒品、违禁品及其交易或制作信息。
4. 诈骗、盗号、钓鱼链接及窃取账号或财产的信息。
5. 游戏币、账号、外挂等黑产广告或交易引流。
6. 电话、社交账号、群号、外部二维码描述等站外联系方式引流。
7. 暴力、仇恨、歧视、威胁和骚扰。
8. 垃圾广告、机器灌水、大量重复或低质量复制内容。
9. 与梦幻西游及本站允许讨论范围完全无关的内容。
10. 通过标题与正文组合、拆字、谐音、编码、零宽字符或其他方式规避审核的内容。
11. 政治相关内容。

第一期没有图片能力，因此图片与标题、正文组合规避属于未来媒体阶段的强制预留政策，
本期不实现图片识别或 OCR。

## 3. 政治相关内容的暂定口径

按用户确认的宽口径处理：

- 现实政治人物、组织、党派、选举、政府政策、政治运动和政治宣传。
- 现实国际政治、领土争议、政治事件和相关立场动员。
- 借游戏内容影射、引战或传播现实政治内容。

单纯出现可能同时属于游戏语境的词语，不应仅凭一个词直接判定违规；上下文不明确时进入
人工审核。

## 4. 审核阶段

### 4.1 输入规范化

保留原文用于证据与人工审核，同时生成仅用于检测的规范化文本：

- Unicode 规范化。
- 全角与半角统一。
- 大小写统一。
- 去除零宽和不可见控制字符。
- 识别异常空格、拆字、重复标点和常见字符替换。
- 提取 URL、域名、联系方式特征和高重复片段。

规范化文本不得覆盖用户原文。

### 4.2 确定性强规则

强规则至少覆盖：

- 明确违禁词或高风险组合词。
- 外部 URL、危险域名和联系方式模式。
- 重复灌水、超长重复字符和完全重复投稿。
- 明确与允许主题无关的广告模板。
- 已封禁内容指纹和重复提交。
- 绕过检测的零宽字符、异常编码和拆分模式。

规则结果分为：

- `critical`：高度疑似严重违规，置顶人工审核队列。
- `warning`：存在风险或上下文可能误判，标记证据供人工判断。
- `clear`：未命中已知规则，但仍须人工审核。

规则表必须版本化、可审计、可灰度，禁止把全部规则散落硬编码在 route 中。

### 4.3 人工终审

审核员需要看到：

- 原始标题与正文。
- 原始内容与规范化内容的差异。
- 规则命中的字段、片段、分类、风险级别和规则版本。
- 作者近期投稿与审核结果。
- 固定且版本化的审核政策说明。

风险分类枚举至少包含：

- `sexual_content`
- `gambling`
- `illegal_goods`
- `fraud_or_phishing`
- `game_black_market`
- `offsite_redirection`
- `violence_hate_harassment`
- `spam_or_duplicate`
- `off_topic`
- `moderation_evasion`
- `politics`

最终决策只有两类人工操作：

- `approve`：审核员确认内容符合政策，允许进入发布流程。
- `reject`：审核员确认内容不符合政策，必须记录至少一个分类和理由。

系统不得根据规则结果自动调用 `approve` 或 `reject`。规则预审异常时，投稿保留在待审队列
并标记系统错误，由管理员处理或重新执行规则检查。

## 5. 审计与申诉

每次审核记录：

- 内容修订 ID。
- 原始内容的完整性摘要。
- 规则版本和政策版本。
- 各阶段输入引用、输出、耗时和错误。
- 人工决定、操作者、时间和理由。

是否在第一期提供用户申诉入口仍待确认，但数据结构不得阻止后续增加申诉。

## 6. 真实样本要求

规则验收前，需要用户提供或确认来源合法的真实样本，至少覆盖：

- 正常梦幻西游攻略。
- 游戏内包含“交易、赌博、政治”等易误判词语但语境正常的内容。
- 每个禁止分类的违规样本。
- 拆字、谐音、零宽字符、联系方式和链接规避样本。
- 重复灌水和跨帖复制样本。

没有真实样本时可以实现机制，但不能宣称规则召回率、误判率或审核质量已经验收。
