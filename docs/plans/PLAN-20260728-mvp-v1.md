# PLAN-20260728 梦幻西游攻略站第一期 v1

> 状态：已于 2026-07-29 经用户确认。按阶段执行，每阶段独立验证并向用户报告。

> 执行状态：阶段 1–4 已完成本地实现；阶段 5 的本地联调已完成，生产联调受
> Cloudflare 认证阻塞；阶段 6 进入文档收口和 GitHub 推送。

## 1. 第一阶段：工程骨架与契约

- 按已确认边界实现“纯文本攻略投稿”，不实现主题帖、回复、评论、点赞或私信。
- 按已确认边界实现默认开放注册、阈值自动切换邀请码、用户登录和管理员登录。
- 实现超管专属的注册模式、阈值步长、一次性和每周定时开放配置。
- 实现受 `BOOTSTRAP_TOKEN` 保护的首次初始化，并保证数据库中最多一个超管。
- 固化普通用户、管理员、唯一超管三级权限矩阵。
- 按已确认的宽口径处理政治相关内容，歧义项由人工终审。
- 使用已确认的 TypeScript、React Router、Cloudflare Vite Plugin、Workers、D1
  和 Wrangler 技术基线；新增依赖必须完成必要性、许可证和 Workers 兼容性检查。
- 固化目录、页面、HTTP API、MCP 和错误契约。
- 创建 React Router + Cloudflare Vite Plugin + Wrangler 骨架。
- 配置 lint、typecheck、unit test、build、preview 和 deploy 命令。

验收：

- 本地 Worker 环境可以启动。
- 空应用通过 lint、typecheck、test 和 build。
- Wrangler 仅存在一份权威配置。

## 2. 第二阶段：D1 与内容主链路

- 定义 schema、索引、外键和 migrations。
- 实现唯一超管初始化、账号、会话、角色权限、注册策略、草稿、修订和公开内容查询。
- 实现攻略列表、详情、分类和搜索页面。
- 执行本地 D1 migration 和状态机集成测试。

验收：

- 草稿与待审修订不能被公共页面或 API 读取。
- 只有已发布修订可被搜索和访问。
- 编辑已发布内容时旧修订继续公开。
- 空数据库只能创建一次超管，管理员不能授予角色或变更超管状态。
- 第 100、200 名等默认阈值边界自动切换邀请码；定时窗口与阈值组合通过矩阵测试。

## 3. 第三阶段：规则预审与人工终审

- 实现文本规范化和版本化强规则。
- 实现规则风险排序、证据、决定和人工审核队列。
- 实现失败关闭和管理员审计日志。
- 使用用户提供的真实样本验证规则命中与误判（样本尚未提供，保留为生产前验收项）。

验收：

- 每个规则有单元测试和真实样本编号。
- 所有投稿均进入人工审核；规则异常时不得发布。
- 管理员操作可追溯。

## 4. 第四阶段：只读 MCP

  `get_published_guide`。

验收：

- 返回站内规范 URL、更新时间和内容状态。
